## 🎯 文档用途说明

### 1. 详细说明文档
**适用人群**: 开发者、系统管理员、项目维护者
**内容包含**:
- 项目概述和特性
- 完整的工程结构说明
- 核心文件详细功能
- 使用说明和配置方法
- 故障排除和调试指南
- 扩展开发指导
- 最佳实践建议

### 2. 快速参考指南
**适用人群**: 运维人员、快速部署需求
**内容包含**:
- 快速安装命令
- 常用操作命令
- 故障排除步骤
- 紧急操作指南
- 配置文件位置

### 3. 技术架构图
**适用人群**: 架构师、技术决策者
**内容包含**:
- 系统整体架构图
- 组件关系图
- 数据流程图
- 服务生命周期
- 网络架构图
- 安全架构图

### 4. README文档
**适用人群**: 新用户、项目概览
**内容包含**:
- 项目简介
- 基本安装方法
- 核心功能说明
- 快速开始指南
