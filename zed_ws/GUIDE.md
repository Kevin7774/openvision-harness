> 未验证的东西一律去 [WORKING.md](./WORKING.md)。这份文件的每一条都要能指出证据。

## 1. 抓取只走「像素伺服 + 竖直下降」两件工具，不进标定链

| 工具 | 命令 | 干什么 | 证据 |
|---|---|---|---|
| 对齐＋下降（**同一步**） | `servo.py step --blob U,V [--go]` | (du, dv, dz) 方阵解，见 §2 | 08-14 四步 106.9→9.1px；08-17 方阵解 dry-run 精确砍半 |
| 纯竖直下降 | `plan_descent.py --z Z [--go]` | 冻结 tip 的 x/y，只改高度 | 08-17 两次 −70mm，残差都是 **0.0mm** |

`plan_descent` 现在只在「明确只想改高度」时用。它**不检夹爪体**（import 了 `_grip_safe`
却没调用），靠的是 `ik_center` + `plan_path` 的指尖地板和碰撞检查 —— 这就是为什么它降得
下去而伺服的同样下降会被夹爪体模型否决。知道这条差别，才不会把两者的拒动理由搞混。

**为什么不用一次 IK 直达积木**：世界系还剩 ~100mm 未定位误差（大概率相机外参），
`solve x y` 那条链 38 次抓取 0 成功。伺服量的是**像素差**，常量偏移在差分里为零。

## 2. 二维对齐 ≠ 三维到位，而「交替」是**错的**：z 必须进误差向量

夹垫在图像里跨住积木时，指尖仍可能高出桌面 200mm（08-17 实测：tip z=1.001，桌面 0.790）。

~~所以序列是 `descend → servo → descend → servo`~~ ——**这条 08-17 被实测推翻**。
`J` 是 2×3、活关节 3 个，`pinv` 取最小范数解，而「夹垫在图上往上走」最省力的实现就是
**抬手臂**。逐步用现成 FK 复算，7 步伺服把两次下降的 70mm 原样抬回去：

```
0.8610 → .8814 → .8875 → .8924 → .8956 → .9104 → .9192 → .9253 → 0.9305   合计 +69.5mm
每步 +3.3~20.4mm，抬升幅度和 |e| 成正比
```

所以「交替」是走一步退半步的楼梯；而「先偏置预补偿下降视差、再盲降」更糟 —— 偏置向量
**正好是 z 变化的图像特征**，伺服照它走就是把 z 变回去（自指，Experiment 09）。

**正确做法**：把系统补成方阵，(du, dv, dz) 三个约束配 3 个关节，恰定。z 行由
`servo._jz` 数值微分现成 FK 给出，**没有新标定常量**。下降和像素修正是同一个动作。
`GRASP_TIP_Z` 同时是 z 目标和硬下限。damp=0.5 会精确地把三个分量各砍一半 —— 这是
精确解的指纹，也是验收方阵解有没有接对的最省事判据。

## 2b. 越靠近，**重新检出目标越不可信** —— 该钉死它

积木是静止的（四帧同窗放大：顶边一直 v≈256~261）。但夹垫从图像上方压过来时，
检出的是「**可见部分**的质心」，于是目标每步往上跑 ~3px，最后积木被切成两片碎团、
双双落进 `PAD_GUARD_PX` 被排除，只剩背景里的浅木色纸巾盒。
⇒ 先人工核对一张原图，然后 `servo.py step --blob U,V` **钉死**目标像素。
积木被挪动过才重新给（Cycle 之间必须重新给）。

## 4. 每次开工的前置检查（都是曾经咬过人的）

```bash
export ROS_DOMAIN_ID=12 RMW_IMPLEMENTATION=rmw_fastrtps_cpp   # 缺了看到的是空图
source /opt/ros/jazzy/setup.bash && source /opt/ros/astrabot/setup.bash
python3 xr1.py status        # 要看到 READY arms / ZED（6 个 zed TF frame）
python3 xr1_cam.py doctor    # 录制器是**独占**的；state=recording 说明上一场没停
```

- 头 `pitch=+40°(实测 39) / yaw=0`，yaw 偏一点就是半米级误差。
- 夹爪命令要在 DDS 发现完成后发，`xr1.py grip()` 已修根。
- `timeout N python3` 拦不住 rclpy 脚本，兜底只有 `kill -9`。

## 5. 录像

`xr1_cam.py start <clip>` / `stop` / `pull <clip> --dest DIR`，clip 名就是文件名。
Mac 侧 `/Users/apple/xr1rec/clips/*.mov`，ssh 要 `-i ~/.ssh/id_xr1rec`。
1080p30 约 **2 MB/s**，所以一场实验录 1 分钟 ≈ 120MB，别让它空跑。
