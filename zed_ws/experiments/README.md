# experiments/ 总览

共 1 个实验目录（1 次成形的试验，0 次没构成实验）。另有若干 **run 目录**（含 `run.json`）归 `xr1_experiment.py` 管，不在此表。

这份总览和每个目录里的 `REPORT.md` 都由 `scripts/exp_report.py` 生成，是 `meta.json` + `record.jsonl` 的纯函数，可以随时重新生成。

## 怎么读一次试验

```
20260810-14/
  REPORT.md       ← 人读：结论 / 走到第几关 / 比上次强在哪 / 关键测量
  summary.json    ← 机器读：同一份数据的结构化版本（派生，可重新生成）
  meta.json       ← 原始事实：参数、裁定、代码 sha1（一次写死）
  record.jsonl    ← 原始事实：事件流，一行一个事件
  *.jpg           ← 过程照片
```

- `REPORT.md` / `summary.json` 是**派生**的，随时可重新生成，别手改。
- `meta.json` / `record.jsonl` / `index.jsonl` 是原始事实，`exp_report.py` 从不写它们。
- 人写的「这次比上次改了什么」在 `lineage.json` 里，重新生成不会冲掉。

重新生成：

```bash
python3 scripts/exp_report.py            # 只看计划
python3 scripts/exp_report.py --apply    # 落盘
```
